## 🎮 게임 소개

> **"만져라! 메이드 인 와리오"** 스타일의 초고속 미니게임 컬렉션입니다.
> 단, 당신이 놓친 한 판이 **인류의 역사를 바꿉니다.**

- ⏱️ **한 판에 3~8초** — 설명은 없다. 화면을 보고 바로 반응해야 한다
- 🕰️ **시대순 진행** — 빅뱅 → 석기 → 청동기 → 중세 → 근대 → 현대 → 미래
- 🦋 **나비효과** — 실패는 게임 오버가 아니라 **다른 역사**가 된다
- 🎨 **2D 실사풍** — AI로 생성한 실사 이미지가 만드는 기묘한 이질감

<br>

### ✨ 엔딩은 정해져 있지 않습니다

> **당신이 만든 역사를 LLM이 읽고, 그 자리에서 서사를 씁니다.**

- 📖 **미리 써둔 엔딩이 없습니다** — 사전 제작한 분기가 아니라, 판이 끝나는 순간 **런타임에 생성**됩니다
- 🎭 **당신의 플레이가 곧 대본입니다** — 어느 시대에서 무엇을 성공하고 실패했는지가 그대로 서사의 재료가 됩니다
- 🌠 **스타워즈풍 크레딧 롤** — 빅뱅부터 미래까지, 인류사 전체를 관통하는 **거창한 한 편의 사평**으로 흘러갑니다
- 🖼️ **엔딩 이미지도 함께 생성됩니다** — 겪은 사건들이 **하나의 장면으로 융합**된 실사풍 이미지가 배경에 떠오릅니다
- 🔀 **조합은 2ⁿ가지** — 같은 엔딩을 두 번 보기 어렵습니다

```
마녀를 잡지 못한 세계  →  "마녀는 살아남았고, 지금 당신 옆자리에 앉아 있다."
마녀를 잡은 세계      →  "마녀는 동화 속으로 물러났고, 세계에서 마법이 지워졌다."
```

> 💡 게임은 당신을 평가하지 않습니다. 실패는 '못한 것'이 아니라 **그렇게 흘러간 역사**로 서술됩니다.

### 핵심 재미

| | |
|:---|:---|
| 🔥 **시대별 맞춤 미니게임** | 석기시대엔 불 붙이기, 중세엔 마녀 찾기, 근대엔 페니실린 골라내기 |
| 🔗 **역사의 인과관계 체험** | "그때 그게 안 됐다면?"을 손으로 겪는다 |
| 🪞 **의도된 데자뷔** | 중세의 *마녀 색출*과 근대의 *페니실린 선별*은 **같은 화면·같은 조작**이다. 손이 먼저 알아챈다 |
| 🎲 **매번 다른 엔딩** | 성공/실패 조합이 2ⁿ가지 → 엔딩 텍스트·이미지를 **런타임 생성** |

### 게임 흐름

```
🌌 빅뱅 (프롤로그)
    │  실패 → 게임 오버, 다시 빅뱅부터
    ▼
🪨 석기 → 🏺 청동기 → ⚔️ 중세 → 🏭 근대 → 🌆 현대 → 🚀 미래
    │           고정 순서로 전부 재생
    ▼
📜 엔딩 크레딧 (스타워즈풍 롤)
    ▼
✍️ 세계 이름 짓기 → 🖼️ 갤러리에 영구 보관
```

### 미니게임 3종

| 종류 | 실패하면 | 예시 |
|:---:|:---|:---|
| ⚪ **일반** | 그냥 넘어간다 | 손 비비기, 삽질 |
| 🔵 **변화** | 흐름은 이어지되 **엔딩 서사·이미지에 반영** | 자동차 발명, 컴퓨터 해킹, 주식 |
| 🔴 **핵심** | **즉시 엔딩으로 직행** | 불 피우기, 청동 제련 |

> 💀 실패한 미니게임은 **패널티**를 남깁니다. 화면에 먼지가 끼거나, 쥐가 지나다니거나, 귀신이 따라붙습니다 — 한 판이 끝날 때까지 계속됩니다.

### 엔딩 & 갤러리

- 📝 **크레딧 텍스트** — Gemini가 당신의 판을 읽고 대체 역사를 서술합니다
- 🖼️ **엔딩 이미지** — 겪은 사건들을 하나의 장면으로 융합해 생성합니다
- ✍️ **세계 이름 짓기** — 방금 만든 역사에 직접 이름을 붙입니다
- 🏛️ **갤러리** — 이미지 + 크레딧 + 세계 이름이 한 덩어리로 **영구 저장됩니다**

> 🔌 API 없이도 완주됩니다 — 생성에 실패하면 폴백 생성기가 대신 대본을 만듭니다.

## 🕹️ 조작법

| 키 | 동작 |
|:---:|:---|
| `W` `A` `S` `D` / `↑` `↓` `←` `→` | 이동 · 커서 |
| `Space` | 결정 · 연타 · 타이밍 |
| `마우스` | 드래그 · 클릭 (일부 미니게임) |
| `ESC` | ⚙️ 설정 (BGM · 효과음 · 해상도) |

> ⌨️ 게임 시작 전 **키 가이드**가 자동으로 표시됩니다.

### 🤖 런타임 AI (엔딩 생성)

| 용도 | 프로바이더 | API 키 |
|:---|:---|:---:|
| 크레딧 텍스트 | **Gemini** `gemini-3.6-flash` | 필요 |
| 엔딩 이미지 | **Pollinations** (flux) | 불필요 |

> ⚠️ Gemini 이미지 모델은 무료 티어 일일 한도가 0이라 사용할 수 없습니다 → Pollinations를 기본값으로 사용합니다.
> 🔑 키는 소스에 넣지 않습니다 → 환경변수 `GEMINI_API_KEY` 또는 `StreamingAssets/gemini_api_key.txt` 로 주입됩니다.

## 📁 프로젝트 구조

```
Assets/
├── 00_Scenes/        씬 (00000_Player = 미니게임 호스트, 00_BigBang = 시작)
├── 01_Scripts/
│   ├── Core/         🧩 미니게임 프레임워크 (MiniGame · MiniGamePlayer · GameFlowController)
│   ├── Ending/       📜 엔딩 크레딧 · 이미지 LLM 생성
│   ├── Gallery/      🏛️ 엔딩 영구 보관 & 열람
│   ├── Settings/     ⚙️ 오디오 · 화면 설정
│   ├── Title/        🏠 타이틀 화면
│   └── Mini_*/       🎮 미니게임별 스크립트
├── 02_Sprite/        스프라이트
├── 03_Prefabs/       미니게임 프리팹
└── 04_Video/         영상 에셋

docs/                 📚 설계 문서 (미니게임 계약 · 엔딩 · 갤러리 등)
```

> 📦 미니게임은 **프리팹 단위**로 제작하며 씬에 직접 배치하지 않습니다.
> 📄 새 미니게임을 만들기 전 [`docs/MiniGame_Contract.md`](docs/MiniGame_Contract.md)를 먼저 읽어 주세요.

## 🚀 실행 방법

```bash
git clone <repository-url>
```

1. **Unity `6000.3.7f1`** 로 프로젝트 열기
2. *(선택)* 엔딩 텍스트 생성을 쓰려면 API 키 설정
   - 환경변수 `GEMINI_API_KEY` 설정, **또는**
   - `Assets/StreamingAssets/gemini_api_key.txt` 에 키 저장
3. `Assets/00_Scenes/00000_Title.unity` 열고 ▶️ Play

> 🔧 키가 없어도 폴백 텍스트로 정상 플레이됩니다.
